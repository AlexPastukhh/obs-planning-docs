  "text": "## Final Review — версии без постоянно поддерживаемого `current`\n\nПервое завершённое review — **Final Review v1**, без фиктивного MR0 и без дубликата. Для содержательного отчёта это один полноценный Markdown с canonical Findings/PR, доказательствами и ограничениями; для тривиального результата отдельный файл не обязателен.\n\n**Устойчивая identity:** один Review ID для линии (`R-17`) и неизменяемые версии (`R-17/v1`, `/v2`), каждая с точным target/scope, версией проверяемого объекта, датой среза и подтверждённой ссылкой. Не переиспользуй identity для иного объекта/существенно иного scope без основания.\n\n**Не сохраняй `current / historical` в версии как нуждающееся в обновлении состояние.** Каждая опубликованная версия — исторический snapshot независимо от того, была ли она последней в момент выпуска. Для ответа найди доступные версии по проверенным источникам/ссылкам и называй **последнюю подтверждённо найденную**; если нет полного охвата истории, обозначь `более новая версия возможна / не проверена`. Дата, имя и фраза «current» внутри старого файла не доказывают текущесть. Незавершённую исправленную редакцию называй `candidate` как статус **этого черновика**, не второй статус всей линии. Не распространяй выводы review на новую версию underlying объекта без повторной проверки.\n\nПредыдущие versioned paths неизменны, новые версии размещай отдельно. По умолчанию не создавай manifest, pointer/index или отдельный Review Log для отслеживания актуальности; если проект уже имеет согласованный canonical owner/индекс, используй его по разрешённым правилам, а не придумывай конкурирующее состояние. `forfiles` — копия для чтения, не изменение project state.\n",
