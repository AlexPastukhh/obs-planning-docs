Scenario / Realization Review\n\nЕсли задача имеет Desired Scenario/SRU structure, проверь:\n- правильно ли единица размещена в реализации Scenario;\n- не избыточен ли состав SRU;\n- не появилась ли преждевременная сложность;\n- есть ли validation-first/staged вариант с лучшим option value;\n- не найден ли upstream P/R/U/O, который должен быть решён до дальнейшей детализации.\n\n## 6. Findings / Proposals\n\nКлассифицируй замечания как `F-P/F-R/F-U/F-O`, а Evidence Gaps отдельно. Questions прикрепляй к соответствующим findings. User Assistance / Dependencies\n\nПроверь, не пропущено ли небольшое пользовательское действие, способное снять blocking/неоправданную сложность, и не был ли, наоборот, пользователь привлечён без необходимости.\n\n## 8.
