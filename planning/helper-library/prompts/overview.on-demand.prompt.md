Цель — чтобы пользователь быстро понял суть, итог, важность и следующий шаг, **не читая подробный отчёт**.\n\n**Target / основания.** Явный target пользователя важнее последнего сообщения или файла. Добавляй disposition, когда это необходимо для понимания отсрочки или закрытия. Для нескольких PR покажи значимые альтернативы, а не один «средний статус». Допустима короткая таблица; не дублируй HIGH/CRITICAL целыми абзацами. Не проводи новое review и не выдумывай отсутствующие ID, статусы, приоритеты, PR или доказательства: недоступное обозначь `неизвестно/не оценено`. `Proposal committed` ещё не означает `Finding resolved`; rejected Proposal не аннулирует находку. При отсутствии Findings не создавай искусственный реестр.\n\n\n**Рекомендуемый порядок / наборы (если доступны).** Если исходный результат содержит взаимозависимые PR по одному или разным Findings, покажи короткий общий маршрут: совместимые `PR/PG-*`, порядок или параллельные группы, причины prerequisites, нужные решения/evidence/verification перед переходом, альтернативы при существенном конфликте.
