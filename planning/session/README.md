# Session Work

Generic reusable guidance for conducting an active work session.

Session work starts from the actual situation. Repository documentation may materially improve the work, but it does not automatically dictate the Session Workflow.

## Contents

- [`principles-and-terminology.md`](principles-and-terminology.md) — Session Concern, Session Workflow, Session State, Guidance Orientation, guidance usage, and Checkpoint meaning.
- [`use-case-registry.md`](use-case-registry.md) — current Session Use Cases.
- [`use-cases/`](use-cases/) — functional owners.

Persistence transport, GitHub synchronization, UI/viewer behavior, and command tooling are downstream technical concerns and are not owned here.
