# UC-SESSION-ESTABLISH-WORKFLOW — Establish / Adjust Session Workflow

## Situation

The current work needs a clearer concern, working structure, or way of proceeding, or the existing Session Workflow no longer fits the situation.

## Result

The Session has a situation-appropriate current concern and way of working, with enough structure to continue productively without forcing an unnecessary methodology or file structure.

## Process

1. Start from the actual situation and the useful result currently being sought.
2. State or refine the current Session Concern when doing so improves orientation.
3. Identify material parent/sub-concerns, dependencies, or subplans only when the work actually needs them.
4. Decide how the work should proceed now: discussion, planning, research, review, production, decision, Checkpoint, persistence, or another useful action.
5. Inspect repository guidance when reusable information may materially improve the work.
6. Use [`UC-SESSION-USE-REPOSITORY-GUIDANCE`](UC-SESSION-USE-REPOSITORY-GUIDANCE.md) when documentation orientation itself needs to be made explicit.
7. Create or restructure Session State only when persistence/working complexity justifies it.
8. Adjust the Session Workflow whenever the situation materially changes.

Shared meaning: [`../principles-and-terminology.md`](../principles-and-terminology.md)

The Session Workflow is situation-owned. It is not required to reproduce one saved Process exactly.
