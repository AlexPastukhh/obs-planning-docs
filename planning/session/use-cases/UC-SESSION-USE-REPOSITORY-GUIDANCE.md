# UC-SESSION-USE-REPOSITORY-GUIDANCE — Use Repository Guidance In Current Session

## Situation

Repository documentation may materially improve the current work, and it is useful to make the selected guidance and its current implications observable.

## Result

The Session has a situation-specific Guidance Orientation: relevant repository owners and recommendations are identified, their applicability to the current step is assessed, and useful state/workflow implications, actions, questions, or decisions are visible.

## Process

1. Start from the current Session Concern and actual Session Workflow.
2. Discover or select repository documentation that may be relevant to the current step.
3. Prefer semantic owners and functional Use Cases over random filename browsing.
4. Form the current Guidance Orientation from the owners that are materially useful.
5. For each material recommendation, assess whether it is:
   - applicable as-is;
   - useful with contextual adaptation;
   - useful only as inspiration;
   - better deferred;
   - not useful in the current situation.
6. Distinguish recommendations from choices already selected by the participants.
7. Derive Session State or Session Workflow proposals only where the current work benefits from them.
8. Surface meaningful actions, questions, or decisions when they require attention.
9. When useful, represent the result in a proportional `Session Concerns & Guidance Usage` section near the beginning of the chat response.
10. Keep the section short or omit it when it adds no material orientation.

Shared meaning: [`../principles-and-terminology.md`](../principles-and-terminology.md)

This Use Case does not own the semantic meaning displayed from other repository owners.

A recommendation is not automatically selected or executed.
