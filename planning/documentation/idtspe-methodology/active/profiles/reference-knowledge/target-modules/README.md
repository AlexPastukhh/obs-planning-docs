# Reference Knowledge Target Modules

Current recurring Target families:

- [Bank Formation](TM-RK-05-BANK-FORMATION.md#tm-rk-05-bank-formation)
- [Entry](TM-RK-10-ENTRY.md#tm-rk-10-entry)
- [Vocabulary Evolution](TM-RK-20-VOCABULARY-EVOLUTION.md#tm-rk-20-vocabulary-evolution)
- [Landscape Analysis](TM-RK-50-LANDSCAPE-ANALYSIS.md#tm-rk-50-landscape-analysis)

Do not promote every bank operation into a Target Module. Ordinary Tag Assignment, Relation, Analysis and small owner-clear corrections remain ordinary operations unless current work exposes an independently useful bounded responsibility under the normal IDTSPE Core routing rules.

Coordinated work across several Entries may use a Local Target Contract when the coordination itself is independently useful, but each Entry still follows ordinary create/refine/retire/successor semantics; this does not reintroduce merge/split identity-surgery primitives.
