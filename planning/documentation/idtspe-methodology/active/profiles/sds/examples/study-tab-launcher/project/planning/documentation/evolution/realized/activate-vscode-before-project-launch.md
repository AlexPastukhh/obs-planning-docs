# EVO-STL-ACTIVATE-VSCODE-BEFORE-PROJECT-LAUNCH — Activate VS Code before project launch

Status: realized lineage from repository v0.14.0. Current behavior belongs to
the materialized Features and Scenarios.

## Entering From

[EVO-STL-REUSE-EXISTING-TRUSTED-PROJECT](reuse-existing-trusted-project.md).

## Realized transition

Split the found-source journey into focus and launch phases. The external URI
carries only the opaque prepared token, activates VS Code, and launch redemption
runs after a bounded allowance. Project data, destination and trust choices do
not cross in the focus URI.
