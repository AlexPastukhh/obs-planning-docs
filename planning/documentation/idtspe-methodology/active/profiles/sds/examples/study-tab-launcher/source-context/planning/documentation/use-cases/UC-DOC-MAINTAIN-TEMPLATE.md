# UC-DOC-MAINTAIN-TEMPLATE — Maintain Documentation Template

## Situation

A repeated output or Process shape is useful enough to standardize, or an existing template is stale, over-prescriptive, semantically overloaded, or no longer used.

## Result

A shape-only current template exists where useful, remains reachable from the Use Case/Process that uses it, and contains no semantic decision logic that belongs in another owner.

## Process

1. Confirm that a stable repeated shape actually provides reuse value.
2. Keep semantic rules in the owning Use Case, Process, or Principles & Terminology.
3. Put only the reusable shape in the template.
4. Keep optional sections optional and avoid fields that are not needed across the intended uses.
5. Prefer inline examples/shape when a separate template would add no reuse value.
6. Ensure the template is reachable from at least one current operational Use Case.
7. Update consumers when the stable shape changes.
8. Retire or mark legacy templates that no current Use Case needs.
