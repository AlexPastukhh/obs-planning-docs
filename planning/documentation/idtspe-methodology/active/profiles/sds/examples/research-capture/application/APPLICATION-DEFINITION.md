
# Research Capture — Application Definition

Target Module: `TM-APPLICATION-DEFINITION`  
Status: selected worked-example owner

## Concept

A lightweight temporary research-capture application separates **fast preservation during reading** from **later review/triage**.

## Responsibility Boundary

Inside:

```text
accept capture
preserve selected material + source context durably
optional short thought
truthful success/failure feedback
later temporary review/triage
```

Outside:

```text
browser/reader itself
full long-term knowledge management
mandatory universal export framework
```

## Build / Buy / Adapt Position

Existing bookmark/read-later/note tools partially satisfy the Need but do not provide the selected low-interruption fragment+context+thought workflow strongly enough for this worked route.

Selected example position:

```text
small custom Application contribution
+ integrate with existing long-term destination later
```

## Core Real-Life Route

```text
notice useful material
→ capture fragment + source context with low interruption
→ resume reading
→ later review/triage temporary captures
```

## Feasibility

No blocking feasibility issue found. Interaction interruption remains uncertain enough for a Prototype.
