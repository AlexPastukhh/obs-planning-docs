
# Research Capture — SDS Planning State

```text
SDS-PLANNING-STATE/
├── SDS-EVOLUTION-MAP.md
├── SDS-WORKSPACE-EVOLUTION.md
└── ideas/
```

`SDS-EVOLUTION-MAP.md` owns what/roughly when product/system evolution is planned/credible.

`SDS-WORKSPACE-EVOLUTION.md` is the `TM-WEUC` interpretation of those items as Workspace/architecture evolution paths.

Loose Ideas remain under `ideas/` and do not become Evolution Items automatically.
