
# Research Capture — Screen Map

Target Module: `TM-SCREEN`

## Screens / Surfaces

```text
Reading / Capture Surface
  capture action
  selected material/source context

Capture Result Surface
  truthful success/failure feedback

Review Inbox
  accumulated temporary captures
```

## Scenario × Screen

```text
SCN-RC-CAPTURE
  Reading / Capture Surface
  Capture Result Surface

SCN-RC-REVIEW
  Review Inbox
```

## Routes

```text
Reading / Capture Surface
→ Capture Result Surface
→ back to reading

Review Inbox
→ selected item detail / later transfer flow
```

Screen placement does not redefine Scenario behavior.
