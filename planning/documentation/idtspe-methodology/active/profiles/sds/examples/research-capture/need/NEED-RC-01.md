
# NEED-RC-01 — Preserve Useful Research Material Without Breaking Reading Flow

Target family: Need / Reality

## Need

Useful research material should remain available for later use without forcing long organization/context switching during the reading moment.

## Current Reality

```text
manual notes:
  precise but interruptive

bookmarks/read-later:
  low effort but too coarse for fragment + thought
```

## Success Meaning

```text
capture intended material + enough source context reliably
optionally preserve a short thought
return to primary reading work quickly
```

## Open Solution Slot

No software/application/architecture is selected here.
