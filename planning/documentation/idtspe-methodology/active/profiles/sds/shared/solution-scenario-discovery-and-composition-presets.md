
# Real-Life Solution Discovery / Composition — Optional Presets

Status: active optional pattern aids  
Owner of formation mechanics: `resolution-slot-and-target-formation-resolution-set.md`

These are reusable **examples**, not mandatory Target Types.

## Preset A — One Bounded Real-Life Route Target

Useful when one real-world situation/result deserves independent comparison.

Suggested local shape:

```text
Target identity
Need Source
Actor / context
Starting situation
Desired real-world result
Current route(s)
Gap / friction
Solution slot
Questions
candidate route Ideas
Evidence / constraints
selected route/result
outside
downstream handoff
```

Example:

```text
Target:
  choose low-friction way to preserve research material

Ideas:
  bookmark
  read-later app
  notes
  custom capture
```

## Preset B — Portfolio / Inventory Discovery

Useful when one Need exposes several independently meaningful scopes.

Output example:

```text
T-A
T-B
T-C

relations:
  T-A PARALLEL_WITH T-B
  T-B FLOW_TO T-C
```

These are candidate Target Instances; labels/forms are selected through Target Formation.

## Preset C — Material Composition Target

Use only if combining accepted outputs creates a new material choice.

Suggested local questions:

```text
Which accepted routes can coexist?
What order/flow is selected?
What shared responsibility exists?
Which route combination best serves the Need?
What is explicitly outside?
```

Example:

```text
Option 1:
  user captures directly into long-term notes

Option 2:
  user captures into temporary holding,
  reviews later,
  then transfers selected items
```

If choosing between these combinations is material, composition deserves its own Target.

If accepted parts already combine without a new choice, do not create it.

## Preset D — No New Target

If accepted Sources already determine the route and there is no material unresolved choice:

```text
reuse accepted result
→ hand it downstream
```

Target Formation is allowed to terminate without inventing another planning owner.
