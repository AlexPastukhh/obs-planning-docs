## Boundary
Evidence capture itself is not automatically IDTSPE.

```text
actual Evidence
→ compare with accepted Decision basis / residual Q/R/P / watch signals
→ reaffirm
or
→ reopen narrowest Answer / Question Set / Target Scope / upstream Target
```

When a Decision reopens, use the relevant Target Module and the full generic IDTSPE cycle again.

## Outputs
```text
actual test/acceptance Evidence
coverage findings
semantic drift/consistency findings
Observed WEUC Evidence
revalidation dispositions
updated residual Q/R/P / helpers
trusted Sources for the next cycle
```

No unrelated Target is reopened without a concrete challenge.


## Evolution Feedback

```text
planned/candidate evolution item
→ implemented / challenged / deferred / retired
→ observed Change Axis / WEUC Evidence
```

Do not convert every discovered future Idea directly into architecture pressure; promote it through an explicit evolution/planning basis first.
