# Construction Route Selection

Select the construction route during Target/module formation when the representation is not already fixed by the request/current accepted state.

```text
task + accepted Sources + required editable result
→ AI route recommendation + rationale
→ USER selection when not already explicit/current
→ selected construction Target Module(s)
```

Reopen route selection when new Evidence materially shows that the current representation/tool route cannot economically preserve required fidelity, editability or downstream use.

## Selection Signals

Ask proportionally:

- Must individual target-grid pixels be exact?
- Must semantic parts remain independently editable/swappable?
- Is scalable path/shape geometry dominant?
- Is non-destructive layered raster editing dominant?
- Is painterly brush/edge behavior dominant?
- Is the visual fundamentally parameter/field/pattern driven?
- Are many controlled variants/frames expected?
- Is there an existing canonical source format that must be preserved?
- Do several route results require material integration ownership?

## Route Families

- exact native target-grid pixels → [Pixel Art Construction](../target-modules/TM-2D-31-PIXEL-ART-CONSTRUCTION.md#tm-2d-31-pixel-art-construction)
- semantic paths/shapes/scalable clean geometry → [Vector Construction](../target-modules/TM-2D-31-VECTOR-CONSTRUCTION.md#tm-2d-31-vector-construction)
- layered masks/strokes/non-destructive raster editing → [Editable Raster Construction](../target-modules/TM-2D-31-EDITABLE-RASTER-CONSTRUCTION.md#tm-2d-31-editable-raster-construction)
- organic painting as the dominant production language → [Painterly Raster Construction](../target-modules/TM-2D-31-PAINTERLY-RASTER-CONSTRUCTION.md#tm-2d-31-painterly-raster-construction)
- parameter/field/noise/mask-driven families → [Procedural Construction](../target-modules/TM-2D-31-PROCEDURAL-CONSTRUCTION.md#tm-2d-31-procedural-construction)

If several accepted route results combine mechanically, hand them downstream as Sources.

If their combination introduces material integration/composition meaning, use [Multi-route Visual Construction](../target-modules/TM-2D-30-VISUAL-CONSTRUCTION.md#tm-2d-30-visual-construction).
