# Exact Realization Integration

Construction Unit Resolution may invoke Core Exact Realization whenever literal source creation or modification is needed.

```text
Unit Resolution
→ exact source construction/modification
→ implementation-native source + review preview
→ inspect
→ Evidence/Finding when material
→ refine Unit result and source
```

Repeat locally as needed. Construction does not wait for all planning work to finish before creating inspectable source.

Preview/render output is review material unless the active owner explicitly makes that representation canonical.
