# LENS-REPRESENTATION-EDITABILITY-ECONOMY — Source Representation Economy

Lens ID: `LENS-REPRESENTATION-EDITABILITY-ECONOMY`  
Activation: `TARGET_PROFILE_REUSABLE`  
Status: active profile Lens

## Purpose / Evaluation Objective

Evaluate whether the selected editable representation/structure/tool route is economical for the required visual meaning, local revision, reuse and outputs.

## Applicability Gate

Apply when choosing/reviewing pixel/vector/raster/procedural route, semantic part/layer structure, hybrid composition or when source complexity/editability becomes a material concern.

## Target Inputs / Evidence

Requirements; expected changes/variants; current source structure; selected route; actual edit/review evidence; alternative route candidates when material.

## Supported Operations

ANALYZE, CHECK, REFINE, CHALLENGE

## Evaluation Workflow / Prompts

Ask:

```text
what meaning must stay independently editable?
what local revisions are likely?
are parts/layers/parameters paying for themselves?
is a simpler representation sufficient?
is current route forcing awkward workarounds?
will output fidelity survive rasterization/export?
is procedural/reuse complexity justified by repetition/variation?
```

## Typical Findings / Outputs

over-structured source; under-structured destructive source; route mismatch; needless generator/procedural complexity; semantic parts coupled despite expected local revision; editability cost greater than value.

Useful explanation may remain Broad Discussion/Key Points. Only material meaning needing ownership/lifecycle disposition becomes a Finding Candidate.

## Typical Consumers

Target Formation route selection; route Unit Opening/Closing checkpoints; Multi-Route Composition; Construction Review Loop.

## Guards / Anti-patterns

Editability is not maximal decomposition; do not prefer code/vector/procedural forms merely because they are structured; preserve painterly economy when organic painting is the value.

## Composition

Compose with Core Simplicity/Need/Value concepts when available and with Construction Fidelity.

## Escalation / Revalidation

Recheck when expected variants/revisions/output constraints or actual editing evidence changes.
