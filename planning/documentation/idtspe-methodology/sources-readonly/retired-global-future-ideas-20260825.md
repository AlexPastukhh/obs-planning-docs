# Future / Unassigned Ideas Inbox

Status: active working owner  
Purpose: preserve useful Ideas that arise during one planning Target but do not belong to the current scope and do not yet have a selected future Target.

Fundamental rule:

```text
Idea in this file
≠ Current Plan
≠ accepted Decision
≠ implementation authorization
```

AI-generated Ideas are allowed here and must be marked as AI proposals.

---

# Entry Contract

```text
Idea ID

Status:
  PROPOSED | UNTRIAGED | DEFERRED | ROUTED | RETIRED

Origin:
  USER
  AI_PROPOSAL
  EVIDENCE
  PRIOR_PLANNING
  OTHER_SOURCE

Discovered During:
  Phase / Target / Decision

Potential Need / Problem:
  what might make this Idea useful?

Idea:
  candidate answer / direction

Why Preserve:
  why not discard it now?

Possible Future Target:
  known target identity/type
  or UNKNOWN

Alternatives Known:
  optional

Evidence / Assumptions:
  optional

Q/R/P:
  only material concrete concerns

Routing:
  where to move/reference it once a real Target exists

Decision Status:
  UNSELECTED
```

---

# Routing Rule

When a later planning Target becomes current:

```text
resolve relevant Inbox Ideas
↓
treat each as an Idea Source
↓
evaluate against current Need / Sources / Lenses
↓
user/authorized Decision selects or rejects
```

Do not copy an Inbox Idea into current semantic truth merely because it was preserved.
