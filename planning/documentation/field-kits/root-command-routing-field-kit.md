# Root Command Routing Field Kit

Status: active reusable bootstrap field kit
Scope: setup only, before a project has a current command-routing owner.

Create:

```text
planning/command-routing.md
planning/commands/README.md
planning/commands/<command>.command.md
```

Required semantic neighbors:

```text
planning/direction-registry.md
relevant use-case-registry.md
```

After runtime owners exist, stop using this field kit as a router. Commands remain optional shortcuts to semantic Use Cases rather than the repository's primary navigation.
