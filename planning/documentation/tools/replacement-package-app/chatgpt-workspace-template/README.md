# ChatGPT Work Sandbox Template

Status: partial bootstrap template; reusable methodology content is not fully integrated yet.

Copy the **contents of this directory** to a fresh local sandbox Work folder when starting one independent Work.

```text
<work>/
├─ ALWAYS-READ.md
├─ METHODOLOGY/
├─ SOURCE/
└─ FILES/
```

The sandbox is disposable. Durable Work/session continuity must live outside it. The intended durable owner is the planned Session State repository/system, which should eventually store/provide the authoritative sandbox bootstrap template used to reconstruct a fresh local Work folder.

`METHODOLOGY/` currently contains registry placeholders only. It is intentionally incomplete until the reusable methodology snapshot/layout is finalized.
