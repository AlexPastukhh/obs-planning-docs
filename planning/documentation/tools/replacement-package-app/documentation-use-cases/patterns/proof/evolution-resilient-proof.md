# Pattern — Evolution-Resilient Proof

**Problem / pressure:** important proof becomes brittle or incoherent as materially known behavior evolves.

**Prefer:** explicitly decide whether proof should remain unchanged, extend, be supplemented or legitimately change when semantics change; keep the proof structure maintainable across the known evolution chain.

**Possible Items:** Test Item specifying expected evolution behavior of proof.
