# Pattern — Cohesive Responsibility / Local Reasoning

**Problem / pressure:** understanding or changing one responsibility requires holding a large unrelated application graph in mind.

**Prefer:** boundaries that keep one semantic responsibility and its proof locally understandable/navigation-friendly.

**Possible Items:** responsibility boundary, locality/dependency constraint, local proof requirement.
