# Legacy Idea Terminology Compatibility

Status: compatibility/provenance only; **not a current methodology owner**
Purpose: preserve historical `Idea` links/IDs while mapping the former Idea concept to the current IDTSPE Proposal lifecycle.

## Canonical Mapping

```text
legacy Idea
= current Proposal

legacy Idea Review
= current Proposal candidate review

legacy Idea Variant
= same Proposal refinement when identity is unchanged
  OR another Proposal when the answer is materially different/selectable independently

legacy Current Selected Variant
= selected Proposal meaning represented through Decision / Target Result / natural owner

legacy Possible Idea Refinement
= Proposal refinement / REVISE candidate

legacy Idea Group
= Proposal relations or Candidate Bundle only when that current semantic meaning actually fits
```

Canonical current owner:
[`idtspe-methodology/active/idtspe-core/shared/proposal-and-decision-lifecycle-contract.md`](idtspe-methodology/active/idtspe-core/shared/proposal-and-decision-lifecycle-contract.md).

[`idtspe-methodology/active/idtspe-core/shared/qrp-lifecycle-and-review-contract.md`](idtspe-methodology/active/idtspe-core/shared/qrp-lifecycle-and-review-contract.md).

## Preserved Review Intent

Useful former Idea-review checks were migrated to Proposal candidate review:

- Need/driver fit;
- Necessity / Better Route;
- refinement;
- local consistency;
- integrated consistency;
- combination evaluation when several Proposals are intended to coexist;
- Evidence/risks/assumptions/constraints and reconsideration when material.

This file does not define those checks independently anymore.

## Compatibility Boundary

Natural-language `idea` remains ordinary language. Historical `IDEA-*` identifiers may remain as provenance/compatibility references when useful.

Current methodology must not create a separate Idea State kind, Idea-owned Current Plan, Idea Decision type, Idea Variant lifecycle or dedicated Idea authority beside Proposal.

Old files that still say `Idea` are interpreted through the mapping above until migrated. New files use `Proposal`.
