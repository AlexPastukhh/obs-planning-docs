# Current Semantic Consistency Review Workflow

Status: active reusable owner
Semantic entry: `UC-DOC-REVIEW-CURRENT-CONSISTENCY`

## Purpose

Check whether current registries, canonical semantic owners, templates/workflows/projections and navigation agree on selected meaning after material methodology/documentation change.

## Review

Check proportionally:

- semantic identity and owner uniqueness;
- registry ↔ owner route completeness;
- current vs candidate/deferred/retired truth;
- stale duplicate rules/projections;
- UC/Scenario-first planning invariant;
- Q/R/P owner/provenance attachment;
- Review Order as lens only;
- selected dependency/architecture/testing handoffs;
- local links/references plus semantic discoverability.

Mechanical link success does not prove semantic consistency.

## Result

Return checked files/semantic units, contradictions/stale/orphan routes, selected corrections or explicit no-material-defect result, and hand off to `UC-DOC-MAINTAIN-REGISTRIES`, `UC-DOC-MAINTAIN-NAVIGATION` or the affected canonical owner as needed.

This is review-only; it does not grant repository mutation permission.
