# AI Working Contract Template

Status: active reusable template

A repository using this methodology should expose a root AI/chat contract from natural repository navigation.

The contract must require the chat to:

1. resolve the current Direction / Use Case before material work;
2. read applicable reusable documentation/planning principles;
3. follow canonical owner routes rather than filenames/examples/projections by assumption;
4. keep implementation and documentation ownership distinct;
5. preserve no-silent-promotion boundaries;
6. treat command invocation as an optional executable shortcut, not the only discovery mechanism.

The contract routes to owners; it does not copy their complete methodology.
