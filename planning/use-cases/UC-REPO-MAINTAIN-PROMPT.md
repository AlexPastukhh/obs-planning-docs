# UC-REPO-MAINTAIN-PROMPT — Maintain Reusable Prompt

## Situation

Reusable prompt/insertion text would materially improve repeated AI interaction, or an existing prompt is stale, duplicative, too broad, or routes to obsolete owners.

## Result

A reusable prompt exists that performs its interaction/bootstrap job concisely while deferring semantic authority and permission to current repository owners/routes.

## Process

1. Define the repeated interaction job the prompt should help perform.
2. Resolve the current semantic owners/routes the prompt must navigate rather than duplicate.
3. Keep only the minimum reusable instruction/context needed for the interaction job.
4. Make authority, freshness, evidence, and permission boundaries explicit when material.
5. Validate that the prompt remains an aid/projection rather than a second semantic owner and place it in the current helper/prompt area.
